สร้างภาพจริงยังไง? ออกแบบภาพ 2500×1686 (Canva/Figma) ตามกริดนี้ แล้วอัปโหลดผ่าน LINE Developers Console หรือ Messaging API (POST /v2/bot/richmenu + อัปโหลดรูป). หน้านี้ใช้เป็น “แบบ” ให้ดีไซน์ตามได้เลย
โครงสร้าง Rich Menu (LINE Messaging API)

วางเป็น JSON ตอนสร้าง Rich Menu — แต่ละ area จับคู่ปุ่มกับพิกัด + action

{
  "size": { "width": 2500, "height": 1686 },
  "selected": true,
  "name": "buoy-main-menu",
  "chatBarText": "เมนูทุ่นตรวจน้ำ",
  "areas": [
    { "bounds": {"x":0,   "y":0,   "width":833,"height":843},
      "action": {"type":"message","text":"ค่าล่าสุด"} },
    { "bounds": {"x":833, "y":0,   "width":834,"height":843},
      "action": {"type":"uri","uri":"https://real-time-marine-water-quality.onrender.com"} },
    { "bounds": {"x":1667,"y":0,   "width":833,"height":843},
      "action": {"type":"postback","data":"action=location"} },
    { "bounds": {"x":0,   "y":843, "width":833,"height":843},
      "action": {"type":"uri","uri":"https://real-time-marine-water-quality.onrender.com"} },
    { "bounds": {"x":833, "y":843, "width":834,"height":843},
      "action": {"type":"postback","data":"action=alert_settings"} },
    { "bounds": {"x":1667,"y":843, "width":833,"height":843},
      "action": {"type":"postback","data":"action=help"} }
  ]
}
ขั้นตอนติดตั้ง (สรุป):
  1. สร้าง Rich Menu ด้วย JSON ข้างบน → ได้ richMenuId
  2. อัปโหลดรูป PNG 2500×1686 เข้ากับ richMenuId นั้น
  3. ตั้งเป็นเมนูเริ่มต้น: POST /v2/bot/user/all/richmenu/{richMenuId}
  4. ปุ่ม postback (ตำแหน่ง/แจ้งเตือน/ช่วยเหลือ) ให้ bot ตอบผ่าน webhook ตาม data=
