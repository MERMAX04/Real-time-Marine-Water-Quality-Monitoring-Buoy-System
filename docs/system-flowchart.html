Edge Reader / Uplink

ส่งคำสั่ง Modbus ไปอ่านทะเบียน 0x2600 (44 ไบต์ = 11 float) แล้วถอดค่า จับคู่เป็น 8 พารามิเตอร์ ก่อนยิงขึ้นคลาวด์

ตอนนี้USB-RS485 → คอมพิวเตอร์ รันสคริปต์ Python (sensor_to_supabase.py) — พิสูจน์ทั้งวงจรได้โดยยังไม่ต้องมี ESP32
ภาคสนามESP32 + โมดูล 4G (LilyGO A7670) จ่ายไฟด้วยแบต 12V + โซลาร์ — ลอยกลางทะเลส่งเองอัตโนมัติ พร้อม GPS ในตัว จับพิกัดทุ่น (lat/lon) ส่งไปด้วย

ผู้ใช้งานเฝ้าดูคุณภาพน้ำ

Monitoring

ดูค่าคุณภาพน้ำทะเลแบบเรียลไทม์ได้จากทุกที่ เห็นแนวโน้ม รับการแจ้งเตือนเมื่อค่าผิดปกติ — ใช้ตัดสินใจ/เฝ้าระวังสิ่งแวดล้อมชายฝั่ง

หมายเหตุการอ่านแผนผัง

สเตจ 2คือหัวใจที่กำลังพัฒนา — “ตอนนี้” ใช้คอมพิวเตอร์อ่านผ่าน USB เพื่อทดสอบ ส่วน “ภาคสนาม” จะย้ายไป ESP32 + 4G โดย Supabase และ Dashboard ไม่ต้องแก้อะไรเลย
GPSโมดูล 4G รุ่น A7670 มี GPS ในตัว จับพิกัดทุ่น (lat/lon) ส่งไปเก็บคู่กับค่าน้ำ แล้วแสดงเป็นการ์ด “ตำแหน่งทุ่น” บน Dashboard — รู้ว่าค่านี้มาจากจุดไหนในทะเล
แผนสำรองถ้า Supabase มีปัญหา สลับ CONFIG.mode = server ให้ Dashboard ไปอ่านจาก Server อาจารย์ (PHP+MySQL) ที่เก็บข้อมูลชุดเดียวกัน — ไม่ต้องแก้โค้ดส่วนอื่น
เรียลไทม์จุดที่วิ่งบนเส้นท่อแทน “ข้อมูล 1 ชุด” ที่ไหลจากเซนเซอร์ถึงหน้าจอ ใช้เวลารวมเพียงไม่กี่วินาที

ระบบทุ่นตรวจวัดสภาพน้ำทางทะเลแบบเรียลไทม์ · Sensor → Edge → Supabase → Dashboard
