## 7.2 Feature ที่วางแผนจะเพิ่ม
| ลำดับ | ฟีเจอร์ | ประโยชน์ | สิ่งที่ต้องทำ |
|---|---|---|---|
| 1 | **ส่งซ้ำ + เก็บข้อมูลสำรองบนทุ่น** | ไม่เสียข้อมูลเมื่อ 4G หลุดชั่วคราว | ลองส่งซ้ำ 2–3 ครั้ง · เก็บแถวที่ส่งไม่สำเร็จใน flash/SD แล้วส่งย้อนหลัง (ส่ง `created_at` ไปด้วย) |
| 2 | **ติดตั้งหัววัดเสริม** ORP / คลอโรฟิลล์ / น้ำมัน / สาหร่าย | เฝ้าระวังสาหร่ายบลูมและการปนเปื้อนน้ำมัน | ติดหัววัด → เพิ่มคอลัมน์ในฐานข้อมูล → อ่านช่อง 5/6 ในเฟรม และ register `0x260D`/`0x260E` (OIW/BGA ใช้ช่องร่วมกัน) → เพิ่มเกณฑ์ใน `water-modes.json` |
| 3 | **เทรนด์รายวัน/สัปดาห์ + heatmap** | เห็นแนวโน้มและรูปแบบรายชั่วโมง | ใช้ view `readings_daily` (รายละเอียด [`5-extensions/03-trends-heatmap.md`](../5-extensions/03-trends-heatmap.md)) |
| 4 | **หลายทุ่นบนแผนที่รวม** | ขยายเป็นเครือข่ายสถานี | ตาราง `devices` + โหมดต่อทุ่น + ตัวเลือกสถานี (รายละเอียด [`5-extensions/04-multi-buoy-map.md`](../5-extensions/04-multi-buoy-map.md)) |
| 5 | **ค่าฐานธรรมชาติ (baseline) ต่อจุดติดตั้ง** | ประเมินอุณหภูมิ/ความเค็มตามถ้อยคำกฎหมาย | เก็บค่าฐานรายจุดแล้วเทียบ "ค่าที่เปลี่ยนไป" |
| 6 | **จัดการพลังงาน** | ใช้งานกลางทะเลได้นานขึ้น | อ่านแรงดันแบตเตอรี่ · ลดความถี่การส่งเมื่อแบตต่ำ · deep sleep ระหว่างรอบ |
| 7 | **ตั้งค่าทุ่นจากระยะไกล** | เปลี่ยนรอบส่ง/ค่าตั้งโดยไม่ต้อง flash | ทุ่นอ่านค่าตั้งจากตาราง config ในฐานข้อมูล · OTA firmware update |

## 7.3 แนวทางการพัฒนาต่อ (เชิงเทคนิค)
1. **รวมตรรกะประเมินไว้ที่เดียว** — ให้เว็บเรียก Edge Function ประเมินแทนการมิเรอร์ตรรกะใน JS และให้ PHP อ่านผลจากแหล่งเดียวกัน ลดความเสี่ยงที่ 3 ภาษาไม่ตรงกัน
2. **ให้ WQI อ่านช่วงค่าจาก `water-modes.json`** — ตัดแหล่งเกณฑ์ที่ซ้ำในตัวแปร `PARAMS`
3. **เพิ่ม automated test** — unit test ของ `evalWater()` ด้วยชุดข้อมูลจากกรณีทดสอบ 23 กรณี (`deno test`) และรันอัตโนมัติก่อน deploy (GitHub Actions)
4. **ปรับความปลอดภัยแอดมิน** — ใช้ Supabase Auth หรือ token ที่มีวันหมดอายุแทน hash ของรหัสผ่าน
5. **นโยบายเก็บข้อมูล** — เก็บข้อมูลดิบระยะสั้น (30–90 วัน) และเก็บค่าเฉลี่ยรายวันระยะยาว เพื่อไม่ให้เกินพื้นที่ของ free tier
6. **Machine Learning** — ใช้ข้อมูลที่สะสมพยากรณ์แนวโน้มและตรวจจับความผิดปกติที่ซับซ้อนกว่าวิธีสถิติที่ใช้อยู่ (Holt smoothing, z-score)
