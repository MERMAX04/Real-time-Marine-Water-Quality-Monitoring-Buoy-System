# 📋 สรุป Protocol ของ Sensor (ดึงจากคู่มือ Online Multi-parameter Sensor)

เอกสารนี้สรุปทุกอย่างจากคู่มือ sensor ที่จำเป็นต่อการเขียนโค้ดอ่านค่า
(คู่มือจริงเป็น PDF สแกน อ่านยาก — สรุปไว้ที่นี่แทน)

---

## 1. การสื่อสาร (หน้า 20)
- โปรโตคอล: **Modbus RTU** (sensor เป็น slave)
- **Baud rate: 9600**
- **Data bits: 8 | Parity: None (N) | Stop bit: 1**  → เรียกสั้นๆ ว่า **9600 8N1**
- **Slave address เริ่มต้น: 0x01** (เปลี่ยนได้ที่ register 0x3000)

## 2. การต่อสาย (หน้า 8) ⭐ จุดที่ทำให้ "ไม่ตอบกลับ"
สาย sensor มี 4 เส้น:
| สี | หน้าที่ | ต่อไปที่ |
|----|---------|----------|
| 🔴 **แดง** | VCC (ไฟเลี้ยง +) | แหล่งจ่ายไฟ **DC 12–24V** ขั้ว + |
| ⚫ **ดำ** | GND | ไฟขั้ว − **และ** GND ของ RS485 adapter (ground ร่วม!) |
| 🟢 **เขียว** | 485_A (D+) | ขา **A** ของ RS485 adapter |
| ⚪ **ขาว** | 485_B (D−) | ขา **B** ของ RS485 adapter |

**ไฟเลี้ยง (หน้า 7): DC 12–24V, ≥1A** — USB จ่ายไม่พอ ต้องมี adapter ไฟแยก
> สาเหตุ "ไม่ตอบ" ที่เป็นไปได้สูง: (1) ไม่ได้ต่อ GND ร่วม (2) ไฟไม่ถึง 12V/1A (3) สลับ A↔B

## 3. คำสั่งอ่านค่า (หน้า 21, 25)

### อ่านทุกค่ารวดเดียว (แนะนำ) — register 0x2600, 22 registers
```
ส่ง:   01 03 26 00 00 16 CF 4C
ตอบ:   01 03 2C <44 bytes ข้อมูล> <CRC 2 bytes>
```
44 bytes = **11 ค่า float ตัวละ 4 ไบต์** เรียงตามนี้:

| ไบต์ | ค่า | หน่วย |
|------|-----|-------|
| 00–03 | DO (ออกซิเจนละลายน้ำ) | mg/L |
| 04–07 | Turbidity (ความขุ่น) | NTU |
| 08–11 | Conductivity (การนำไฟฟ้า) | mS/cm |
| 12–15 | pH | - |
| 16–19 | Temperature (อุณหภูมิ) | °C |
| 20–23 | ORP (ศักย์ออกซิเดชัน) | mV |
| 24–27 | Chlorophyll (คลอโรฟิลล์) | µg/L |
| 28–31 | OIW/BGA (น้ำมัน หรือ สาหร่าย) | ppm / cells·mL⁻¹ |
| 32–35 | Salinity (ความเค็ม) | ppt |
| 36–39 | TDS | - |
| 40–43 | DO (%) | % |

### อ่านทีละค่า (base 0x2600 + offset, จำนวน 2 registers)
| offset | address | ค่า | ตัวอย่างคำสั่ง |
|--------|---------|-----|----------------|
| 01 | 0x2601 | DO (mg/L) | `01 03 26 01 00 02 9E 83` |
| 02 | 0x2602 | Turbidity | |
| 03 | 0x2603 | Conductivity | |
| 04 | 0x2604 | pH | |
| 06 | 0x2606 | Temperature | |
| 08 | 0x2608 | Salinity | |
| 0A | 0x260A | DO (%) | |
| 0B | 0x260B | ORP | |
| 0C | 0x260C | Chlorophyll | |
| **0D** | 0x260D | **OIW (น้ำมัน)** | |
| **0E** | 0x260E | **BGA (สาหร่ายสีเขียว)** | |
| 0F | 0x260F | TDS | |

## 4. รูปแบบข้อมูล float (หน้า 26-27) ⭐
- เป็น **IEEE754 32-bit float มาตรฐาน**
- ส่งแบบ **"DCBA / low bit in front" = byte เรียงกลับ (little-endian)**
- **วิธีถอด:** เอา 4 ไบต์ที่รับมาตามลำดับ → ตีความเป็น little-endian float ตรงๆ
  - Python: `struct.unpack('<f', data4)[0]`
  - ตัวอย่างคู่มือ: ไบต์ที่ส่ง `66 66 7B 42` → 62.85 ✓ / `00 00 8D 41` → 17.625 ✓

## 5. Register อื่นที่มีประโยชน์
| address | ความหมาย |
|---------|----------|
| 0x0800 | Sensor Status — บอกว่า probe ตัวไหนต่ออยู่/ปกติ (bit flags) |
| 0x0700 | เวอร์ชัน hardware/software |
| 0x3000 | Device address (เปลี่ยน slave address ได้ 1–254) |
| 0x1100 | ค่าคาลิเบรต K/B รายพารามิเตอร์ |

## 6. ช่วงค่าของแต่ละ probe (หน้า 7-8) — ใช้จูนเกณฑ์ใน Dashboard
- DO: 0–20 mg/L | Turbidity: 0.1–1000 NTU | CT: 0–100 mS/cm | Salinity: 0–80 ppt
- pH: 0–14 | ORP: −1999~1999 mV | Chlorophyll: 0–500 µg/L
- OIW (น้ำมัน): 0–150 ppm | BGA (สาหร่าย): 0–300,000 cells/mL

> หมายเหตุหน่วย: sensor ให้ น้ำมัน=ppm, สาหร่าย=cells/mL ต่างจาก Dashboard เดิม (ppb, µg/L) — ค่อยปรับหน่วยให้ตรงตอนต่อจริง
