# 02 — แจ้งเตือน + บอท Telegram (ทำ "ฝั่งบก" อ่านค่าจาก DB)

เด้งเตือนเข้า **Telegram** เมื่อค่าน้ำเข้าขั้น **วิกฤต** + สั่ง **`/status`** ดูค่าล่าสุดได้ทุกเมื่อ
ตรงเป้าหมาย "ผ่อนแรงคนเฝ้า" (ไม่ต้องนั่งจ้อง Dashboard)

> ✅ **Telegram** (อาจารย์แนะนำ) — Bot API ฟรี, open, ไม่ต้องมี Official Account เหมือน LINE

---

## 🏗️ สถาปัตยกรรม: Telegram อยู่ "ฝั่งบก" ไม่ใช่บนทุ่น

```
🌊 ทุ่น ESP32                 🏝️ ฝั่งบก (ทำงานเอง 24/7)
อ่าน sensor → POST ─────► [DB: readings]
                              │  ├─(มีแถวใหม่)─► เช็คเกณฑ์ → เด้งเตือนวิกฤต
   ผู้ใช้ /start,/status ──► [บอท] อ่านค่าล่าสุดจาก DB → ตอบทันที (<1 วิ)
```

**ทำไมย้ายขึ้นบก** (แทนที่จะให้ ESP32 ยิง Telegram เอง):
| | ESP32 ยิงเอง (เดิม) | ฝั่งบก (ตอนนี้) |
|---|---|---|
| ความเร็ว /status | ช้า (poll 15-70 วิ) | **<1 วิ** (webhook) |
| พลังงานทุ่น | ยิง HTTP หลายครั้ง/รอบ | **POST ครั้งเดียว** |
| ความเสถียร | loop ยาว เสี่ยงแฮงก์ | **ทุ่นเบา = เสถียร** |
| แก้เกณฑ์เตือน | ต้อง flash ทุ่นใหม่ | **แก้บนคลาวด์** |

> ทุ่น (`3-supabase-primary/esp32-supabase-4g.ino`) จึง **ไม่มีโค้ด Telegram เลย** — อ่าน sensor แล้ว POST อย่างเดียว

## ตั้งค่า Bot (ครั้งเดียว ~5 นาที)

### 1) สร้างบอท → ได้ BOT_TOKEN
1. เปิด Telegram หา **@BotFather** → พิมพ์ `/newbot` → ตั้งชื่อ + username (ลงท้าย `bot`)
2. ได้ **token** แบบ `123456789:ABCdef...` → เอาไปใส่:
   - Supabase: `supabase secrets set TELEGRAM_BOT_TOKEN="..."`
   - PHP: `define('TELEGRAM_BOT_TOKEN', '...')` ใน `config.php`

### 2) (แนะนำ) ตั้งเมนูคำสั่งใน @BotFather → Edit Commands
```
status - ดูค่าน้ำล่าสุดทุกค่า
start - สมัครรับแจ้งเตือน
stop - ยกเลิกรับแจ้งเตือน
help - แสดงคำสั่ง
```

### 3) ผู้รับแจ้งเตือน = ใครก็ได้ที่ทัก /start
**ไม่ต้องหา chat_id เอง** — คนที่ทัก `/start` จะถูกเก็บลงตาราง `tg_subscribers` อัตโนมัติ
เพิ่มคน = ให้เขากด Start เอง / เพิ่มบอทเข้ากลุ่มก็ได้

## คำสั่งแชท
| คำสั่ง | ผล |
|--------|----|
| `/start` | สมัครรับแจ้งเตือน (เก็บ chat_id) |
| `/status` | ดูค่าน้ำล่าสุดครบทุกตัว (อ่านจาก DB) |
| `/stop` | ยกเลิกรับแจ้งเตือน |
| `/help` | เมนูคำสั่ง |

## เกณฑ์แจ้งเตือน (โฟกัสค่าที่ "อันตรายจริง" กันเตือนพร่ำเพรื่อ)
| ค่า | เกณฑ์ | เหตุผล |
|-----|-------|--------|
| DO | < 3 mg/L | ออกซิเจนต่ำ สัตว์น้ำเสี่ยงตาย |
| pH | < 7 หรือ > 9 | น้ำกรด/ด่างผิดปกติ |
| อุณหภูมิ | > 33 °C | น้ำร้อน เสี่ยงปะการังฟอกขาว |
| ความขุ่น | > 40 NTU | ตะกอน/ปนเปื้อนสูง |

- **กันเตือนซ้ำ**: cooldown 30 นาที/ชนิด (เก็บใน `alert_state`)
- ไม่ตั้งเกณฑ์กับความเค็ม/Conductivity เพราะทดสอบในอากาศ (ค่า=0) จะเตือนรัวๆ
- อยากดู **ทุกค่าอย่างใกล้ชิด** → ใช้ `/status` (auto-alert เตือนเฉพาะวิกฤต)

## แก้เกณฑ์ได้โดยไม่ต้อง flash ทุ่น
- Supabase: `supabase/functions/_shared/telegram.ts` → `evalAlerts()`
- PHP: `4-server-backup/lib/telegram.php` → `tg_eval_alerts()`
