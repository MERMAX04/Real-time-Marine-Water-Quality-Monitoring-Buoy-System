รวมแนวทางพัฒนาต่อ เรียงตามความคุ้มค่า/ความยาก ทำได้ทีละอันตามเวลาที่มี

| # | เรื่อง | ประโยชน์ | สถานะ | ต้องมีอะไร |
|---|--------|----------|-------|-----------|
| 01 | **AI ผู้ช่วยภาษาธรรมชาติ (Claude API)** | สรุป/ให้คำแนะนำเป็นภาษาคน "น้ำเป็นยังไง ควรทำอะไร" | 📋 แนวทาง | server (PHP) + Anthropic API key |
| 02 | **แจ้งเตือน + บอท Telegram** | เตือนค่าวิกฤต + `/status` `/swim` — ผ่อนแรงคนเฝ้า | ✅ **ใช้งานจริงแล้ว** (ทำฝั่งคลาวด์) | Telegram bot (ฟรี) |
| 03 | **เทรนด์รายวัน/สัปดาห์ + heatmap** | ดูย้อนหลังหลายวัน วิเคราะห์รูปแบบ | 📋 แนวทาง | ข้อมูลจริงสะสมใน DB |
| 04 | **หลายทุ่นบนแผนที่จริง** | ขยายเป็นหลายสถานี | 📋 แนวทาง | โครงข้อมูลรองรับหลาย device |
| 05 | **ระบบ 6 โหมดมาตรฐานน้ำทะเลไทย + สถานะลงเล่นน้ำ** | เลือกประเภทการใช้ประโยชน์ → เกณฑ์/สี/สถานะ/แจ้งเตือนเปลี่ยนตามโหมด | ✅ **ใช้งานจริงแล้ว** | ไม่ต้องเพิ่มฮาร์ดแวร์ |
