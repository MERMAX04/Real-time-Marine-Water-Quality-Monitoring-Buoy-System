# 5-extensions — Roadmap ต่อยอด (เตรียมไว้หยิบไปทำได้)

รวมแนวทางพัฒนาต่อ เรียงตามความคุ้มค่า/ความยาก ทำได้ทีละอันตามเวลาที่มี

| # | เรื่อง | ประโยชน์ | สถานะ | ต้องมีอะไร |
|---|--------|----------|-------|-----------|
| 01 | **AI ผู้ช่วยภาษาธรรมชาติ (Claude API)** | สรุป/ให้คำแนะนำเป็นภาษาคน "น้ำเป็นยังไง ควรทำอะไร" | 📋 แนวทาง | server (PHP) + Anthropic API key |
| 02 | **แจ้งเตือน + บอท Telegram** | เตือนค่าวิกฤต + `/status` `/swim` — ผ่อนแรงคนเฝ้า | ✅ **ใช้งานจริงแล้ว** (ทำฝั่งคลาวด์) | Telegram bot (ฟรี) |
| 03 | **เทรนด์รายวัน/สัปดาห์ + heatmap** | ดูย้อนหลังหลายวัน วิเคราะห์รูปแบบ | 📋 แนวทาง | ข้อมูลจริงสะสมใน DB |
| 04 | **หลายทุ่นบนแผนที่จริง** | ขยายเป็นหลายสถานี | 📋 แนวทาง | โครงข้อมูลรองรับหลาย device |
| 05 | **ธงสถานะการลงเล่นน้ำ (Blue Flag)** | บอก "ลงเล่นน้ำได้ไหม เสี่ยงอะไร" ตามเกณฑ์ Blue Flag / คพ.ไทย | ✅ **ใช้งานจริงแล้ว** | ไม่ต้องเพิ่มฮาร์ดแวร์ |

**ลำดับที่แนะนำ (ที่เหลือ):** 03 (มีข้อมูลสะสมแล้วทำง่าย) → 01 (โดดเด่นตอนนำเสนอ) → 04

## ✅ ที่ทำเสร็จแล้ว
- **02 — Telegram:** ย้ายไปทำ **ฝั่งบก** (Supabase Edge Functions + PHP) ทุ่นไม่ต้องแบกงานนี้
  → [`02-alerts-notification.md`](02-alerts-notification.md)
- **05 — ธงลงเล่นน้ำ:** ประเมินจากค่าเคมี/กายภาพ + อ้างอิงมาตรฐานทางการ (มีแหล่งอ้างอิงครบสำหรับใส่ในเล่ม)
  → [`05-blueflag-swim-safety.md`](05-blueflag-swim-safety.md)

> ⚠️ **ข้อควรระบุในเล่ม:** เกณฑ์ชี้ขาดของ Blue Flag คือ **แบคทีเรีย (E. coli / Enterococci)** ซึ่งเซนเซอร์ทุ่นวัดไม่ได้
> ทุ่นทำหน้าที่ **เฝ้าระวังต่อเนื่อง (early warning)** เสริมการตรวจแลป — ดูรายละเอียดในไฟล์ 05
