# 5-extensions — Roadmap ต่อยอด (เตรียมไว้หยิบไปทำได้)

รวมแนวทางพัฒนาต่อ 4 เรื่อง เรียงตามความคุ้มค่า/ความยาก ทำได้ทีละอันตามเวลาที่มี

| # | เรื่อง | ประโยชน์ | ความยาก | ต้องมีอะไร |
|---|--------|----------|---------|-----------|
| 01 | **AI ผู้ช่วยภาษาธรรมชาติ (Claude API)** | สรุป/ให้คำแนะนำเป็นภาษาคน "น้ำเป็นยังไง ควรทำอะไร" | ปานกลาง | server (PHP) + Anthropic API key |
| 02 | **แจ้งเตือนออกนอกจอ** | เด้งเตือน Telegram/LINE เมื่อค่าวิกฤต — ผ่อนแรงคนเฝ้าจริง | ง่าย | Telegram bot (ฟรี) |
| 03 | **เทรนด์รายวัน/สัปดาห์ + heatmap** | ดูย้อนหลังหลายวัน วิเคราะห์รูปแบบ | ปานกลาง | ข้อมูลจริงสะสมใน DB/Firebase |
| 04 | **หลายทุ่นบนแผนที่จริง** | ขยายเป็นหลายสถานี | ปานกลาง-ยาก | โครงข้อมูลรองรับหลาย device |

**ลำดับที่แนะนำ:** 02 (ง่ายและได้ผลไว) → 01 (โดดเด่นตอนนำเสนอ) → 03 → 04

> ทั้งหมดนี้เป็น "แนวทางเตรียมไว้" ยังไม่ได้เปิดใช้ในระบบหลัก ค่อยทำตอนฐาน (Dashboard + cloud + sensor) นิ่งแล้ว
