# 04 — หลายทุ่นบนแผนที่ — 📋 แนวทางพัฒนาต่อ (ยังไม่ได้ทำ)

ขยายจากทุ่นเดียวเป็นหลายสถานี แสดงบนแผนที่รวม เลือกดูทีละทุ่นได้

## โครงข้อมูลรองรับอยู่แล้ว
ออกแบบให้มี `device` ตั้งแต่แรก:
- Supabase / PHP: ตาราง `readings` มีคอลัมน์ `device` + index `(device, created_at)`
- Firmware: ตั้ง `DEVICE_ID` ได้ (ค่าเริ่มต้น `buoy-01`)
- Dashboard: มี `CONFIG.device` · `latest.php` / `history.php` รับ `?device=` อยู่แล้ว
- แต่ละแถวมีพิกัด GPS (`lat`, `lon`) ของทุ่นอยู่แล้ว

## สิ่งที่ต้องเพิ่ม
1. **ตัวเลือกสถานี** — dropdown เลือกทุ่น → เปลี่ยน `CONFIG.device` แล้วโหลดข้อมูลใหม่
2. **ทะเบียนทุ่น** — ตาราง `devices` (ชื่อ / จุดติดตั้ง / โหมดของแต่ละจุด)
   ```sql
   create table devices (device text primary key, name text, mode text);
   ```
   ตอนนี้โหมดมาตรฐานเป็นค่ากลางค่าเดียว (`app_settings.mode`) — ถ้าหลายทุ่นอยู่ต่างพื้นที่ ควรให้โหมดผูกกับแต่ละทุ่น
3. **แผนที่รวม** — วางหมุดทุกทุ่นตามพิกัดล่าสุด สีหมุดตามสถานะรวม (เขียว/ส้ม/แดง) คลิกเพื่อเปิดดูทุ่นนั้น
4. **Telegram** — ระบุทุ่นในคำสั่ง เช่น `/status buoy-02` และระบุชื่อทุ่นในข้อความแจ้งเตือน

## ข้อควรระวัง
- ESP32 แต่ละตัวต้องตั้ง `DEVICE_ID` ไม่ซ้ำกัน (buoy-01, buoy-02, ...)
- ค่า `device` ต้องตรงกันทุกที่ (firmware / ฐานข้อมูล / dashboard)
